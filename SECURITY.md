# Security policy

This is a **public educational repository**, not a production-hardened deployment. Only synthetic data is permitted. Never commit personal data, service tokens, database passwords from real systems or confidential query plans.

To report a vulnerability, do not publish exploit instructions or credentials in an issue. Use GitHub private vulnerability reporting when enabled, or reach the maintainer through their [GitHub profile](https://github.com/mirnurlan-data).

CI is configured for read-only repository access. Keep third-party GitHub Actions reviewed and dependencies current. No support SLA or production security warranty is provided.
